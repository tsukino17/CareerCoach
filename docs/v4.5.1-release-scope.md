## 轻量语音替代方案

### MVP 阶段推荐

使用浏览器 Web Speech API。

优点：

- 不需要模型文件
- 不需要后端语音服务
- 不增加部署体积
- 适合快速验证「文字转语音」体验

缺点：

- 音色普通
- 不适合做品牌化声音
- 不同浏览器效果不完全一致

### 当前产品更推荐的稳定方案

使用云端 TTS，例如 DashScope / 腾讯云 TTS / 火山引擎 TTS。

优点：

- 主项目保持轻量
- 线上稳定性更好
- 适合国内用户访问
- 可以按量付费

缺点：

- 有接口成本
- 需要处理鉴权、限流、缓存

### 后期品牌音色方案

把 GPT-SoVITS 独立成单独服务。

建议结构：

- 主项目：Next.js + Supabase + 管理后台
- 语音服务：单独仓库、单独服务器、单独 API
- 音频文件：Vercel Blob、Supabase Storage 或对象存储

这样主产品不会被 9G 模型拖慢，也不会影响 Vercel 部署。

1. 从当前线上对应的 v4.5 基线新建一个干净分支。
2. 只复制本文档「建议纳入 v4.5.1」中的文件或最小 diff。

   - 本地管理员保底访问
